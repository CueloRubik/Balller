# Balller

Juego arcade cenital para LÖVE 2D. Protege una pelota de pinchos y alcantarillas, consigue puntos y coloca defensas para sobrevivir.

## Inicio

Instala [LÖVE](https://love2d.org/) 11.4 o posterior y ejecuta la carpeta del repositorio con `love .`.

## Controles

WASD o flechas: moverse. Ratón: colocar una defensa. 1, 2, 3: elegir defensa. P o Esc: pausar.

La estructura del juego incluye los módulos `src/`, el punto de entrada `main.lua`, configuración `conf.lua`, recursos `assets/` y documentación.
